# Rummikub Rulebook

A single-page visual guide to Rummikub, designed to be easy to scan and reference mid-game.

## What it is

`rummikub.html` is a self-contained, no-dependencies HTML page that covers every rule you need:

- Tile composition and colours
- Setup and starting hand
- Valid sets (groups and runs), with visual tile examples
- The 30-point initial meld requirement
- How turns work — playing tiles vs. drawing
- Joker rules (retrieval, scoring, substitution)
- Rearranging the table (splitting, stealing, extending)
- Winning and scoring

## Features

- **Colour-coded tile graphics** that match the physical tiles
- **Worked examples** for every rule (groups, runs, joker substitution, splitting)
- **Highlight/warning callouts** for commonly misunderstood rules (no wrap-around, 30-point opener, penalty draws)
- **Quick-reference strip** at the bottom with the key numbers at a glance

## Usage

Open `rummikub.html` in any browser. No build step, no server, no internet connection required.

```
open rummikub.html
```

Works on phone too — the layout is responsive.
